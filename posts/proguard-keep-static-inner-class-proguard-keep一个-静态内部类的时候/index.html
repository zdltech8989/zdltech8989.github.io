- -keepattributes Exceptions,InnerClasses,&#8230;

- -keep class com.xxx.A{ *; }

- -keep class com.xxx.A$B { *; }

- -keep class com.xxx.A$C { *; }

 

这样可以根据需要只保留A的某一个内部类

2018年10月24日 · 1 分钟 · 天边的星星

安装nodemon:

修改package.json

“scripts”: {
“start”: “node ./bin/www”,
“run”:”./node_modules/.bin/nodemon ./bin/www”
},
启动命令 npm run run

nodemon最大的作用就是项目重启，触发重启的事件就是系统文件改变了。因为我们开发过程中经常要对系统文件进行修改，我们每次修改后的通常做法是先退出程序然后再开启程序，这样很劳神费力改一个字都要做这两个步骤，现在好了，我们文件随便改，一改他就重启，这两个步骤就被省略了会大大提高我们的编码效率和减少debug时间。

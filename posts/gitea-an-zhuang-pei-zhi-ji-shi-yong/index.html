Gitea 安装配置#

在很多时候，我们希望有自己的git仓库管理，把我们隐私的一点点工程，放在里面。大家也可以去使用目前网上免费的，例如 github、gitee 、gitlab、 coding.net、gogs、gitea等

Centos 安装Gitea#

  1. 下载gitea wget -O gitea https://dl.gitea.io/gitea/1.12.1/gitea-1.12.1-linux-amd64
  2. 下载下来的gitea是没有 执行权限的，我们需要给他执行权限 chmod a+x gitea
  3. 复制gitea到 /usr/log/bin 方便我们之间执行 cp gitea /usr/local/bin/
  4. 执行 启动 gitea web
  5. 根据gitea 页面信息，进行初始化配置，配置最后所在文件地址 cat /usr/local/bin/custom/conf/app.ini
  6. 如果需要后台运行 使用 nohup gitea >/dev/null 2>&1 & 命令
  7. 完成 开心的使用Gitea吧

通过 ps -ef |grep gitea |grep -v “grep”|wc -l 查询是否运行 返回1 表示运行

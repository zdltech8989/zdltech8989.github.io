今天做了一个Jsoup解析网站的项目，使用Jsoup.connect(url).get()连接某网站时偶尔会出现





java.net.SocketTimeoutException:Read timed out异常。





原因是默认的Socket的延时比较短，而有些网站的响应速度比较慢，





所以会发生超时的情况。







  解决方法：





  链接的时候设定超时时间即可。





  doc = Jsoup.connect(url).timeout(5000).get();





  5000表示延时时间设置为5s。
